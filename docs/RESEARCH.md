# Project Research

Research date: 2026-08-03.

Mooncakes API checks were run before implementation to avoid a highly
overlapping package direction.

## Mooncakes Keyword Check

The following keywords returned no direct package match in the Mooncakes module
API at research time:

- `contrast`
- `palette`
- `wcag`

Related terms showed broader ecosystem activity but not the same scope:

- `color`: general color-space and image-related packages exist.
- `accessibility`: packages exist for broader accessibility or chart output.
- `token`: unrelated tokenization, JWT, or governance packages exist.

## Differentiation

PaletteGuard does not compete with general color-space conversion packages. It
uses simple RGB input as a foundation and focuses on role-aware contrast
policy, report generation, and CI-friendly validation.
