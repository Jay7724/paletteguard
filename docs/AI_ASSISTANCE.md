# AI-Assisted Development Note

PaletteGuard was developed with AI assistance during design exploration,
implementation review, test case generation, debugging, and documentation
editing. The contestant remains responsible for the final project scope,
source code, correctness, security, maintainability, and license compliance.

The final implementation was reviewed against the public API and its tests.
Core behavior is deterministic and covered by executable MoonBit tests for
parsing, WCAG contrast math, color transforms, repair search, token diagnostics,
catalog lookup, ramp validation, matrix export, and Markdown reports. The
repository does not include pasted private code, commercial code, unknown
third-party source, images, fonts, audio, or proprietary test data.

The WCAG relative-luminance and contrast thresholds are implemented as a
public accessibility standard reference. The project does not copy an
external implementation. The built-in palette catalog is synthetic data
authored for this repository. See `THIRD_PARTY.md`, `LICENSE`, `DESIGN.md`, and
`TEST_RECORD.md` for the corresponding source, design, and verification notes.
